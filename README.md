# 小小夢魔：星港理財迷航

給國小學童的 Godot 4 可玩初版。玩家探索原創夢幻貨艙，用星箱配置練習儲蓄、生活需要與分散投資。場景、角色、道具與文字均為原創；Blender 製作的提燈、星星幣和鑰匙會顯示在遊戲右上方。

## 快速開始

在 Windows 上雙擊 `啟動遊戲.bat`。需要 Godot 4.3 以上；預設啟動器位置為 `C:\Godot\Godot_v4.7.2-stable_win64.exe`。

也可以在 Godot 專案管理員匯入本資料夾的 `project.godot`，再執行主場景 `main.tscn`。

## 操作

- 用 A / D 或方向鍵移動；滑鼠點選場景也可移動。
- 按 E 或點左下角「前往發光貨桌」開啟星箱配置。
- 每個貨箱使用「裝箱／取回」調整星幣，再按「確認配置」。
- 鑰匙取得後，走到右側艙門，或使用左下角前進按鈕。
- 結尾畫面可重新開始。

## 兩關內容

1. **先存再花**：配置 10 枚星幣。生活需要至少 5 枚、儲蓄至少 3 枚、想要的東西不超過 2 枚。
2. **分散投資**：把 12 枚星幣分給三家商店。至少分散到兩家，每家最多 6 枚。

每關首次通過得 100 分；錯誤提交扣 25 分，最低 40 分。星幣未分配完時可繼續調整，不扣分。錯誤時會提供學習提示，只有通過配置條件才能取得鑰匙。結尾呈現各關分數、總分與兩項學習成果。

## Blender 素材

可編輯場景位於 `blender/little_dream_props.blend`，生成腳本為 `blender/make_props.py`，遊戲使用的 GLB 位於 `assets/little_dream_props.glb`。遊戲透過 Godot GLTF API 載入 GLB，不需先建立 `.godot` 匯入快取。

## 初版狀態

此版本已完成兩關星箱配置、分數、鑰匙門檻、錯誤提示、結尾進度與重新開始，並已在 Godot 4.7.2 視窗中走完成功與錯誤流程。正式視覺方向尚未由使用者選定；目前畫面是可玩的草稿風格，尚待孩子／教師可用性測試。專案決策與限制記錄在 `docs/` 及 `project-state.yaml`。
