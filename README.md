# 小小夢魔：星港理財迷航

> [開啟瀏覽器試玩版（GitHub Pages）](https://kellyku1025-stack.github.io/game2/)

給國中生的 Godot 4 生活理財教育遊戲。玩家在原創紙雕故事書風格的星港場景中，練習規劃預算、判斷需要與想要、延後衝動消費，並處理突發支出。遊戲內沒有真實金錢或投資交易；投資有風險，不保證獲利。

## 快速開始

GitHub Pages 會把此儲存庫的 Godot 網頁匯出檔託管成靜態網站，讓玩家可用支援 WebAssembly／WebGL 2 的瀏覽器開啟遊戲，不必下載 Godot 或安裝桌面版。每次更新 `main` 分支後，GitHub Actions 會重新匯出並發布。

在 Windows 上雙擊 `啟動遊戲.bat`。需要 Godot 4.3 以上；預設啟動器位置為 `C:\Godot\Godot_v4.7.2-stable_win64.exe`。也可以在 Godot 專案管理員匯入本資料夾的 `project.godot`，再執行主場景 `main.tscn`。

## 操作

- 用 A / D 或方向鍵移動；滑鼠點選場景也可移動。
- 按 E 或點左下角互動按鈕開始目前單元。
- 完成互動取得星鑰，再前往下一個單元。
- 錯誤選擇會提供說明並影響本單元分數；結尾可查看成果或重新開始。

## 四個理財單元

1. **理財配置桌**：把 100% 零用錢分進需要、想要、儲蓄、投資；參考區間允許不只一種配置。未分配到 100% 是提醒，不扣分。
2. **上學購物**：依序逛早餐店、便利商店、傳統雜貨店，將九項商品判斷為需要或想要，並在每項結帳後閱讀原因。
3. **理財紅綠燈**：完成六個情境，選擇立刻買、想一想或先存錢。
4. **突發支出情境**：處理影響上課與安全的臨時眼鏡修理費，練習運用預備金、保留已安排用途並和可信任的大人討論。

每單元滿分 100，錯誤選擇扣 10 分，最低 0 分；完成互動即可取得該單元星鑰。結尾顯示四個單元分數、總分 /400 與完成進度。配置範圍是遊戲教學情境，不是個人理財建議。

## Blender 素材

可編輯場景位於 `blender/little_dream_props.blend`，生成腳本為 `blender/make_props.py`，遊戲使用的 GLB 位於 `assets/little_dream_props.glb`。
